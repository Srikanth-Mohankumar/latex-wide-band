%% figure goes in column 1's top area and sticks out over column 2, whose top area is

%% Every paragraph is a hyperlink, so links run from page to page: the row must keep
%% the rows' box depth (one level deeper stopped AA_9001 with the fatal 'endlink'
%% nesting error).
